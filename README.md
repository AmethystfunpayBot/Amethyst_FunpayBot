# Amethyst

Amethyst — приложение для Windows, которое помогает продавцам FunPay вести заказы и автоматизировать продажи.

- **Заказы и чаты** — переписка с покупателями, история заказов и статусы выдачи.
- **Автовыдача** — правила выдачи и учёт остатков цифровых товаров.
- **Аналитика** — история продаж, статусы средств по заказам, расчёт прибыли и экспорт CSV.
- **Плагины** — дополнительные инструменты для работы с лотами и заказами, включая KOSell Rent.
- **Интерфейс** — русский и английский языки, настраиваемые темы.
